# Studying in the UK

**Developing Judgement, Agency and Confidence while Learning**

A companion website for the forthcoming Routledge book *Studying in the UK* by Dr Qiaoyuan Lin.

**Website:** https://qiaoyuanlin.github.io/studying-in-the-uk/

## About the Project

This website provides practical learning resources for students navigating UK higher education, particularly international students.

Building on the ideas explored in *Studying in the UK*, it aims to help students develop their judgement, agency, confidence and independence through meaningful engagement with learning.

## Learning Resources

The website is being developed to include:

- **Learning with AI:** Practical guidance on using AI while retaining judgement and ownership of learning.
- **Practice & Quizzes:** Interactive activities to help students examine decisions, test understanding and reflect on their learning.
- **Learning Tools:** Downloadable resources, reflection exercises and practical study activities.

Resources will be introduced gradually and refined through teaching experience and student feedback.

## Development

The website is hosted on GitHub Pages and built using HTML, CSS and JavaScript.

It is an evolving educational project, intended to connect ideas from the book with practical learning activities and ongoing developments in education.
